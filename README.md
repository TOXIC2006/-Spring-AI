# Generative AI with Java & Spring AI

A learning project exploring how to integrate **Generative AI with Java and Spring Boot using Spring AI**.

## 🚀 What I Explored

* Spring AI and `ChatClient`
* OpenAI & Google Gemini integration
* Local LLMs using **Ollama + CodeLlama**
* REST APIs for AI responses
* Prompts, tokens, embeddings & RAG basics
* API testing with Postman

## 🛠️ Tech Stack

**Java | Spring Boot | Spring AI | OpenAI | Gemini | Ollama | REST API | Postman**

## 🎯 Goal

To understand how AI models can be integrated into Java applications and build a foundation for developing **AI-powered backend applications**.

More experiments and features coming soon. 🚀
